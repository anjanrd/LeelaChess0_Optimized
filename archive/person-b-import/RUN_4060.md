# Running on the RTX 4060 machine

You only run commands and send files back. Ritwik decides the numbers marked DECIDE.
Run steps in this order, one at a time, never two at once. During studyc, match and hw
close every other program (browser, games, Discord): they change the timings.

## One-time setup
1. `git clone <repo>` and `cd` into it. `pip install -r requirements.txt`
2. Unzip `lc0-v0_33_0-rc0-windows-onnx-trt.zip`, run `install.cmd` inside it (needs internet).
3. Put the TensorRT 10.12 `trtexec.exe` path in config (it is in the TensorRT zip, `bin/`).
4. Syzygy 3-4-5 WDL+DTZ tables in a folder (only the match needs them).
5. Unzip the bundle from Ritwik into the repo folder so you have `data/`, `models/`, `nets/BT3.pb.gz`.
6. `copy config.example.json config.json` and fix the paths (lc0, trtexec, syzygy).
7. Optional, admin prompt: `nvidia-smi -lgc 1500,1500` (locks clocks; if it refuses, ignore).

## Run everything (one command)
```
python overnight.py
```
Leave the laptop plugged in and untouched; close every other program. It runs, in order: day1 (a
check that stops everything if the pipeline is wrong), FP16/INT8 benchmarks, a 50-position timing run
that sizes the study to fit the night, Studies A+B, Study C, the hardware measurements, the match,
and scoring. About 15 hours at the defaults. If it stops, crashes or the PC reboots, run the same
command again: finished stages are skipped and the long ones resume.

When it stops by itself with "STOPPED at day1", do not retry. Zip `reports/` and send it to Ritwik.

Progress: `reports/overnight/summary.md` (one line per stage). Details: `reports/overnight/<stage>.log`.
It writes `send_back.zip` at the end. SEND THAT FILE TO RITWIK.

Shorter night: `python overnight.py --study-hours 3 --match-hours 4`. Skip a stage: `--skip match`.
Look at the plan without running: `python overnight.py --dry-run`.

## If you would rather run the steps by hand
```
python ladder.py day1
python ladder.py hw --parts bench
python ladder.py study --models fp16 --limit 50     # send Ritwik the s/position it prints
python ladder.py study
python ladder.py studyc
python ladder.py hw
python ladder.py match --estimate 2
python ladder.py match
```
Everything is resumable: if a step stops, rerun the same command. Send back `results/` and `reports/`.
